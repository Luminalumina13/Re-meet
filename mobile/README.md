# Re:meeet Mobile

Мобільний застосунок Re:meeet для **iOS** і **Android** на Flutter. Права належать ФОП Павленко Світлані Сергіївні. Застосунок ходить у те саме API, що й веб (`/api/search`, `/api/explore`, `/api/meetup`, `/api/flex`, `/api/watches`), тож бекенд має бути запущений і доступний із пристрою.

**Стек:** Flutter 3.47 / Dart 3.13, Riverpod 3, go_router, dio, shared_preferences, url_launcher, share_plus. Стек збігається з TrackBox24, окрім кодогенерації: тут моделі прості Dart-класи без `build_runner`.

## Що вміє

| Вкладка | Що робить |
|---|---|
| **Пошук** | Аеропорти з підказками (українською й англійською), вихідні або довільні дати, дорослі/діти/немовлята, клас, «зручні години» (у п'ятницю виліт не раніше 12:00), результати з сортуванням, **гнучкі дати ±3 дні**, відстеження, «Поділитися» |
| **Куди** | «Куди завгодно»: від аеропорту, дат і максимальної дороги, картки напрямків, «Усі рейси сюди» переносить у Пошук |
| **Зустріч** | Планувальник: друзі (до 6) з кількома аеропортами, місця зустрічі, баланс «гроші чи час», смуги часу, квитки кожного |
| **Відстеження** | Ваші відстеження цін (їх віддає сервер за токеном власника): перевірити зараз, пауза, підключення Telegram, видалення |
| **Ще** | Мова (UA/EN), тема (системна/світла/темна), політика конфіденційності й умови, версія |

Тема «Сонце» (як у вебі), світла й темна. Посилання «Поділитися» мають той самий формат, що й у вебі, тож відкриваються там (і навпаки).

## Запуск

Бекенд: `npm run dev` у корені репозиторію (порт 3000).

```bash
cd mobile
flutter pub get

# iOS-симулятор: localhost працює напряму
flutter run --dart-define=API_BASE_URL=http://localhost:3000

# Android-емулятор: хост доступний як 10.0.2.2
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000

# фізичний пристрій у тій самій Wi-Fi-мережі: адреса комп'ютера; для iOS потрібен https
# (локальні http-адреси дозволені лише для localhost), для Android debug-збірка дозволяє http
flutter run --dart-define=API_BASE_URL=http://192.168.x.x:3000
```

Змінні збірки:

- `API_BASE_URL`: адреса бекенду (за замовчуванням `https://remeeet.com`).
- `WEB_BASE_URL`: адреса сайту для юридичних сторінок і посилань «Поділитися» (за замовчуванням дорівнює `API_BASE_URL`).

**Без `--dart-define` збірка дивиться на живий сайт `https://remeeet.com`**; для локального бекенду передайте `localhost` явно. Поточну адресу видно на вкладці «Ще».

## Тести

```bash
flutter analyze
flutter test                          # модульні й віджетні тести, без мережі
flutter test integration_test -d <id симулятора> \
  --dart-define=API_BASE_URL=http://localhost:3000     # наскрізні проти живого бекенду
```

- `test/fixtures/` містить знімки справжніх відповідей API, тож зміна форми відповіді бекенду ламає тести моделей.
- Віджетні тести підставляють фальшивий API і перевіряють екрани: перехід із «Куди» у пошук, створення й видалення відстеження, мову, валідацію, стабільну ширину кнопки пошуку.
- Наскрізний тест вводить аеропорти, робить пошук і гнучкі дати проти живого сервера. Якщо задати `SHOTS_DIR`, зберігає знімки екранів.

## Збірки

```bash
# Android
flutter build apk --release --dart-define=API_BASE_URL=https://<ваш-бекенд>
flutter build appbundle --release --dart-define=API_BASE_URL=https://<ваш-бекенд>

# iOS (потрібен повний Xcode і підпис)
flutter build ipa --release --dart-define=API_BASE_URL=https://<ваш-бекенд>
```

Ідентифікатор застосунку: `com.remeeet.app`. **Його треба підтвердити до першого релізу:** після публікації в магазині змінити неможливо.

## Відстеження без акаунтів

Список відстежень приходить із сервера (`GET /api/watches`) за токеном власника, див. розділ про токен нижче. Після видалення застосунку токен губиться, а самі відстеження на сервері лишаються, доки їх не видалять.

## Відстеження і токен власника

Акаунтів немає: трекер належить тому, хто його створив. На першому запуску застосунок генерує секретний токен (32 випадкові байти, 43 символи), зберігає його в Keychain (iOS) або Keystore (Android) і додає до кожного запиту як `Authorization: Bearer <токен>`. Сервер зберігає лише його SHA-256 і віддає трекери тільки власнику, на чужі запити відповідає 404 (`lib/core/owner_token.dart`). Якщо захищене сховище недоступне, застосунок працює з токеном на час запуску.

**Обмеження:** токен прив'язаний до пристрою. Новий телефон або перевстановлений застосунок (на Android без резервної копії) не бачать старих трекерів. Синхронізація між пристроями потребує акаунтів.

## Що ще не зроблено

- **Push-сповіщення.** Сповіщення про зміну ціни йдуть у Telegram (кнопка в картці відстеження). Нативні push потребують FCM/APNs на бекенді.
- **Вхідні посилання.** Посилання «Поділитися» відкриваються у вебі; відкриття їх прямо в застосунку (universal links / app links) потребує домену й файлів `apple-app-site-association` та `assetlinks.json`.
- **Шрифт Manrope** (як у вебі). Зараз системний шрифт.
- **Магазини:** підпис, скріншоти, опис, політика конфіденційності для App Store Connect і Google Play, акаунти розробника.
