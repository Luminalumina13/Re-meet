# Кольорові схеми Re:meeet: архів варіантів

Тут зібрані всі кандидати, які розглядали для оформлення. Зараз у додатку застосована схема **Сонце**.
Попередня схема, **Фіолетовий графіт**, теж лишається тут як варіант (акцент `#6B46E0` вдень, `#9B7BFF` уночі).

## Що де лежить

- `palettes.json`: повні набори кольорів для світлої й темної тем (фони, текст, акцент, статуси, кольори серій) і три кольори «eee» у назві.
- `pages/`: сторінки-порівняння, відкриваються просто в браузері. Кожна показує схеми на міні-екранах застосунку, світла тема зліва, темна справа.
- `preview-tool/PalettePreview.tsx.txt`: смуга вкладок, яка перефарбовує справжній застосунок у будь-яку схему (лише режим розробки).

## Як знову подивитись схеми на справжніх сторінках

1. Скопіюйте `preview-tool/PalettePreview.tsx.txt` у `src/components/dev/PalettePreview.tsx`.
2. Створіть `src/lib/dev/palettes.ts` з експортом `PREVIEW_PALETTES` зі змісту `palettes.json` (тип `PreviewPalette` описаний у компоненті: `name`, `e`, `light`, `dark`).
3. У `src/app/layout.tsx` додайте `{process.env.NODE_ENV === "development" && <PalettePreview />}` перед футером.

Смуга вставляє окремий стиль, тож перемикач світлої й темної теми працює як звичайно.

## Як застосувати схему

Значення з `palettes.json` переносяться в змінні `src/app/globals.css`: `bg`, `surface`, `surface2` у `--surface-2`, `bs` у `--border-strong`, `text`, `text2`, `text3`, `accent`, `hover` у `--accent-hover`, `atext` у `--accent-strong` і `--accent-text`, `soft` у `--accent-soft`, `ink` у `--accent-ink`, `good`, `warn`, `crit` у `--critical`, `s1`..`s6` у `--series-1..6`, три кольори `e` у `--e1..e3`. Також оновіть `public/favicon.svg` і `themeColor` у `src/app/layout.tsx`.
