### Ryanair у нашому коді

`src/lib/providers/ryanair.ts` використовує публічний endpoint fare-finder, який сам сайт ryanair.com застосовує для календарів цін. Це не офіційний API. Умови сайту Ryanair обмежують автоматичне використання третіми сторонами (є й у коментарі в коді, `README.md`, `docs/legal/README.md`). **Для публічного запуску потрібна угода з Ryanair або вимкнення конектора** (`RYANAIR_ENABLED=0`), тоді його рейси доступні через Kiwi.

## Висновки для Re:meeet

1. Одразу доступні: партнерські посилання й Data API Travelpayouts; віджети Skyscanner без реєстрації (без комісії).
2. Потрібен публічний сайт і 5 000 відвідувачів на місяць для Skyscanner; 50 000 MAU для Search API Travelpayouts.
3. Правило Travelpayouts «не поєднувати з іншими метапошуками» суперечить архітектурі кількох провайдерів.
4. Для потягів: розклад без цін через власний MOTIS плюс посилання на перевізника; ціни й бронювання лише через угоду (Trainline, Omio, Distribusion).
5. Для заявок знадобляться дані ФОП і домен.
